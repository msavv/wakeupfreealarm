**Wakesies**

An alarm clock that requires scanning a physical QR code or barcode to turn off.

Completely free forever. No ads, no subscriptions, no accounts, and no locked features.

Features

QR & Barcode Dismissal: Save any QR code or standard barcode (e.g., from product packaging) to an alarm. The alarm only silences once the code is scanned.

Walking Grace Period: A button temporarily mutes the ringing for 30 seconds so you can walk to your code.

Emergency Bypass: A custom text phrase can be typed to disable the alarm if a code is unreachable or unscannable.

Audio Controls: Supports built-in tones and custom local audio files, with an optional volume fade-in up to 5 minutes.

Snooze Limits: Set custom snooze durations or limit snooze attempts to a set count (or disable entirely).

Vibration Modes: Multiple vibration patterns and intensity settings.

Scheduling: Recurring alarm settings with single-tap weekday, weekend, or daily options.

Time Format: Supports 12-hour and 24-hour display.

Offline Operation: Runs entirely on-device without internet access.
